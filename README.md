how to use:

put all the libs, namely:
- belacom.py
- net.py
- render.py
- ascii.py
in a folder called "libs" and install it like a python library (idk go google it)

then make a folder called assets and put the required files (like player_stand.png) in the folder in a path that is as specified by runner.py
run runner.py

PS this project is still incomplete render.py is just a layer of abstraction for making 2d games with pygame easily
